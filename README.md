# Green Empire Tycoon

Browser prototype of a cannabis business tycoon game, built on the project's own illustrations.

Play: https://varneykirk55-collab.github.io/greenline-/

- Drag to look around, pinch to zoom, tap a building to go inside, tap **Street** to come back.
- Progress saves in each player's own browser.
- For quick testing, open the menu (top right) and raise the time speed.

All game code is in `index.html`; art is in `assets/`.
